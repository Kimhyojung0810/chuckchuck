# 04 — 화면별 적용 지도

> 아래 행 번호는 2026-08-06 기준이다. 데모 스프린트 중이라 파일이 자주 움직인다 —
> **행 번호가 어긋나면 함수 이름·클래스 이름으로 grep 해서 다시 찾는다.**

## 1. 전 화면 공통 (토큰만으로 바뀌는 것)

`02_tokens.md` 적용 순간: 배경 회색→크림, 카드 4px→20px, 버튼 초록 갱신, 본문 잉크 갱신.
코드 수정 없이 토큰 값으로만. 이후 화면별 확인:

| 화면 | 확인 포인트 |
|---|---|
| `#/` 홈 | 크림 배경 위 흰 카드 · 다크 verdict 헤드 그라디언트(새 navy) · 764px 세로 예산 안 스크롤 0 유지 |
| `#/new` | 드롭존 dashed 보더가 새 `--border` 와 어울리는지 |
| `#/qa` | 판정 칩 5색 그대로인지 (변하면 안 된다) |
| `#/report` | 탭 바(민트 유리)·판정 헤드·카드 radius |

## 2. 리포트 판정 헤드 (`#/report` 상단)

**대상:** `js/app.js` `reportVerdict()`(~2280-2300) · `renderReport()`(~2340-2373 마크업) ·
`design-system.css` `.verdict-*`(37-119)

| 변경 | 상세 |
|---|---|
| 점수 옆 발표새 | `.verdict-score` 안, 숫자 오른쪽에 52px 엑씨 1마리. `Chatter.chickSvg('ax')` 를 그대로 쓴다 (`window.Chatter` 로 이미 노출돼 있다 — `chatter.js:638-644`). mood 는 점수 티어: ≥90 `excited` / ≥75 `happy` / 그 외 `neutral`. 좌석 래퍼 없이 svg 만 넣으면 mood CSS 가 안 걸리므로 **`<span class="ch-seat" data-mood="…">` 축소 래퍼**로 감싼다 |
| 안내 문구 말풍선 톤 | `realSummary()`(~2641) 의 notes 조립부. "이 상황에서는 평가하지 않는 항목 N개" → "이번 발표 상황에서는 평가하지 않는 항목이 N개 있어요" / "이번엔 측정할 수 없었던 항목 N개" → "이번엔 측정하지 못한 항목이 N개 있어요. 다음 발표에서는 더 많은 피드백을 받아봐요!" — **개수 N 은 반드시 그대로** (정직 원칙). 두 안내는 계속 분리 (합치면 안 된다) |
| 막대 끝 점 | `.verdict-dims .bar i` 에 `::after` 흰 점 (r3). 7개 막대라 별·잎은 소음 |
| 응원 문맥 | 점수가 낮아도 grumpy·슬픔 없음. 헤드 카피는 기존 `headline` 로직 유지 |

주의: verdict 헤드는 다크 면이다 — 크림 몸 발표새가 잘 뜬다. 캐릭터가 파형 배경(`.verdict-bg`)을
가리지 않게 `.verdict-inner` 안(z-index 2)에 둔다.

## 3. 리포트 「청중 반응」 진입 카드

**대상:** `js/chatter.js` `entryCardHtml()`(622-636) · `SEAT_ROLE`(614-619) ·
`css/chatter.css` `.aud-*`(~900-927)

`03_components.md` §4 스케치대로: 틴트 카드 4장 + 캐릭터 + 한 줄 알약 + 이름 + 역할 pill + 모델 배지.
- `aud-status` 문구("…엿들어 볼까요?")와 클릭 → 객석 오버레이 동선은 그대로.
- `SEAT_ROLE` 의 긴 문장은 `.aud-line` 카피로 대체되므로 상수 이름을 유지한 채 값만 03_components §4 표로.
- 4열 그리드 유지 (태블릿 1180px 기준). 763px 이하 대응은 기존 미디어쿼리 따라감.

## 6. playbill 티켓 (canvas) — 색만

`playbill.js` `ticketCanvas()`(190-260)는 **canvas 2D 라 SVG 를 못 받는다.** 도장(원+이름) 구조
유지, `STAMP_COLOR`(39-41)만 새 팔레트로: happy `#08B879` / neutral `#8AA295` / curious `#F0A93C` /
grumpy `#D1584F` (판정 색이 아니라 도장 잉크 — 자유 색).

## 7. 부스 태블릿 수동 체크리스트 (1180×820)

토큰·캐릭터·카드 적용 후, 실기기에서:

- [ ] 홈: 크림 배경 + 흰 20px 카드 + 다크 헤드. 페이지 스크롤 0
- [ ] `#/new`: 업로드 → 상황 4개 선택 화면 정상. 스크롤 0
- [ ] 파이프라인 로딩: 진행 바 + 엑씨. 경과 초 표시 유지
- [ ] `#/report` 헤드: 점수 + 옆 발표새(표정이 점수 티어와 일치) + 말풍선 톤 안내 (개수 정확)
- [ ] 클러스터 막대 7개 라벨 줄바꿈 정상 (`목적·청중 적합성`)
- [ ] 판정 칩 5색 **변화 없음** (ok 초록 / mid 갈색 / no 빨강 / ct 보라 / om 금색)
- [ ] 청중 반응 탭: 틴트 카드 4장, 소품으로 넷 구분, 클릭 → 객석 오버레이
- [ ] 객석: 새 캐릭터 + 말풍선 + 표정 전환 (턴마다 mood 반영), 콕 찌르기 이스터에그
- [ ] 무대 리허설: 실루엣 넷 구분, 반응 연기 (nodding/flipping/…)
- [ ] 커튼콜: 점수 티어별 박수 연출, `data-odd` 손들기
- [ ] 회상 카드·포스터 벽: 티켓 도장 색, 첫 방문 문구
- [ ] OS 모션 최소화 켜고: 모든 캐릭터 애니메이션 정지, 내용은 그대로
- [ ] 새로고침 Ctrl+Shift+R — `?v=` 반영 확인
