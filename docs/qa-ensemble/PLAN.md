## 0. 목표 한 줄
네 국내 모델이 같이 만든 질문이 **발표자가 그 자료의 핵심을 간파하고 있는지**를 묻는다 — 지금 방식보다 더 핵심을 찌르고, 틀리지 않고, 기다리지 않게. 그리고 모든 AI 호출이 제출 가이드대로 남는다.

### 0-1. 핵심 원칙 (사용자, 10/17) — 모든 기준보다 앞선다
> 「슬라이드에는 12000인데 말로는 12300이라 했다 — 이런 미시적인 부분을 파악하는 게 아니라, 정말 해당 자료의 핵심을 간파하고 있느냐를 물어보는 게 우리의 핵심 서비스야.」
- **묻는 것**: 핵심 주장이 무엇이고 왜 그런지, 근거가 주장을 어떻게 받치는지, 주장들이 어떻게 이어지는지, 결론이 어디까지 맞고 어디서 안 맞는지, 이걸 다른 상황에 옮기면 어떻게 되는지.
- **묻지 않는 것**: 숫자 하나·용어 하나·말과 자료의 작은 차이·장 번호 외우기 같은 미시 확인. 숫자는 **결론을 바꾸는 경우에만**(예: 효과가 있다/없다가 그 숫자에 달림) 핵심 질문의 재료로 쓴다.
- **「특화」의 뜻**: 세부를 콕 집는 게 아니라 **이 자료의 논리에만 맞는 질문**(다른 발표에 그대로 쓸 수 없는 질문). 특이도 지표가 세부 질문에 점수를 주면 그 지표를 고친다 — 핵심성 지표(§3 「핵심성」)와 같이 본다.
- 판단 시험: 「이 질문에 잘 답하려면 자료의 핵심 논리를 이해해야 하는가? 자료를 외우기만 해도 답할 수 있는가?」 — 앞이면 좋은 질문, 뒤면 나쁜 질문.

## 2. 실험 원칙
1. **평가 세트를 먼저 고정한다.** 덱을 개발용(dev)과 시험용(test)으로 나눈다. 프롬프트·규칙은 dev 로만 고치고, test 는 단계 게이트와 마지막에만 돌린다(과적합 막기). 주제가 겹치지 않게(공학·사회과학·생활/의학 등) 나눈다.
2. **같은 판을 3번 이상 반복**해서 잡음 폭을 같이 낸다. 「나아졌다」는 짝지은 비교(같은 덱·같은 답)에서 잡음 폭 밖일 때만.
3. **LLM 채점 + 사람 읽기 둘 다.** 작성 모델을 가린 짝 비교 표본을 직접 읽고 판정한다. LLM 심판은 질문을 쓰지 않은 모델로, 순서를 섞는다.
4. **한 번에 하나만 바꾼다.** 가설 → 변경 → 측정 → 장부 한 줄(QA_BENCH_LEDGER) → 게이트 판정. 근거 없이 기본값을 바꾸지 않는다.
5. 실험 호출은 전부 `AI_CALLLOG=all` 로 남긴다.

## 3. 단계와 게이트
각 단계는 **필수 기준을 모두 넘어야 다음 단계로** 간다. 못 넘으면 원인을 찾아 고치고 다시 잰다. 시간 안에 못 넘으면 그 사실과 수치를 그대로 보고한다.

### 1단계 — 모범답 정리
| 기준 | 필수 | 목표 |
|---|---|---|
| 지저분한 모범답(「자료는 이렇게 말해요 —」 접두, 「·」「/」 이어 붙임, 「한계:」 꼬리) | 0 / 30문항 이상 | — |
| 모범답을 그대로 답하면 판정 good | ≥ 95% | 100% |
| 모범답 길이 | 1~3문장 | ≤ 2문장 |
| 모범답 근거 장이 질문 근거 장과 일치 | 100% | — |

### 2a단계 — 개념 그래프 → 질문 대상 지도 (2단계 앞에, 2·3단계가 이걸 쓴다)
지금은 그래프에서 「어느 부분을 어떤 식으로 물을지」가 프롬프트 안에 묻혀 있고, 알려진 한계로 잎 개념을 핵심 주장과 같은 순위로 묻는다(10/2 기록). 이걸 **코드가 정하는 슬롯**으로 체계화한다. 모델은 슬롯을 받아 질문을 쓰고, 「무엇을 물을지」를 맘대로 바꾸지 않는다.

**층 1 — 그래프 위치별 질문 유형 목록(패턴)** — 그래프 자료형: 노드 `thesis·claim·concept`, 엣지 `parent·relates`, 장마다 `claims·evidence·concept_of·title_kind`
| 패턴 | 그래프 모양 | 묻는 것 |
|---|---|---|
| P1 핵심 주장 | thesis(루트) | 한 문장으로 결론, 왜 그 결론인가 |
| P2 근거 충분성 | claim ← evidence | 이 근거로 주장이 충분한가, 다른 해석은 |
| P3 빈 고리 | 근거 없는 claim | 무엇이 이 주장을 뒷받침하나 |
| P4 결론을 좌우하는 조건 | 결론이 달린 evidence(숫자 포함) | 그 조건이 바뀌면 결론이 어떻게 되나 — 숫자 자체를 확인하는 질문은 금지 |
| P5 연결 | claim —relates— claim (장 넘나듦) | 두 주장이 어떻게 이어지나(인과·순서) |
| P6 방법 선택 | 방법·설계 노드 | 왜 이 방법, 대안은 |
| P7 한계·반례 | 한계 노드 / 한계가 아예 없음 | 어디서 안 맞나 |
| P8 개념 이해 | concept 잎 | 핵심 주장에 꼭 필요한 개념일 때만, 「정의가 뭔가」가 아니라 「이 개념이 결론에서 왜 중요한가」 |
| P9 함정 | 자료와 어긋나는 전제 | 틀린 전제를 짚는지 |
| P10 응용·다음 단계 | thesis·결론 장 | 실제로 쓰면, 다음 연구 |
(목록은 실험으로 고친다 — 패턴별 특화도·사람 선호를 재서 버리거나 합친다.)

**층 2 — 발표 겹침(3번+ 질문)**: F-11 대조 + F-10 흐름으로 **핵심 노드(thesis·claim·핵심 연결)**에 `잘 설명함 · 결론만 말하고 이유를 건너뜀 · 흐림 · 핵심과 어긋나게 설명` 을 붙이고, 흐름 문제 `missing_link · order_jump` 를 붙인다. 숫자·낱말이 자료와 조금 다른 것은 신호로 쓰지 않는다.
**층 3 — 답 겹침(3번+ 질문)**: 1·2번 답에서 약했던 노드 → 이웃(부모·자식·relates)으로 이동 규칙: 더 깊이 / 옆으로 / 바로잡기.

**슬롯 점수** = 위계 중요도(루트와의 거리·자식 수) × 발표 신호 × 아직 안 물음 × 각도 다양성. 제약: 같은 장 ≤ 1, 처음 3문항 중 잎 개념 ≤ 1, 1·2번 중 P1/P2 ≥ 1.
**앙상블과 연결**: 슬롯 목록을 네 모델에 똑같이 주고 슬롯마다 후보를 받는다 → 슬롯 안에서 서로 평가·최종 선택. 그래서 중복이 구조적으로 사라지고, 4단계 후보 판에서 「그래프의 어디를 물었는지」 보여 줄 수 있다.

| 기준 | 필수 | 목표 |
|---|---|---|
| 질문이 정말 그 슬롯(노드·패턴)을 묻는지 (가린 심판 + 사람 표본) | ≥ 90% | ≥ 97% |
| 질문 위치 분포: thesis·claim 비율 / 잎 concept 비율 | ≥ 60% / ≤ 25% | ≥ 70% / ≤ 15% |
| 패턴별 특화도·사람 선호 표 | 있음 (패턴 버리기·합치기 근거) | — |
| 같은 덱을 다시 돌렸을 때 같은 노드를 고르는 비율(그래프 흔들림 감안) | 기록 | ≥ 70% |
| 그래프 자체 품질 (10/2 bench.py·repro.py) | 기준선보다 나빠지지 않음 | — |
| 그래프가 틀려서 질문이 틀린 사례 | 따로 세서 보고 (그래프 고치기는 별도 판단) | — |

### 2단계 — 미리 만드는 후보 묶음 + 1·2번 고르기
**품질**
| 기준 | 필수 | 목표 |
|---|---|---|
| 특이도 (vs 기준선, 짝 비교) | 기준선보다 낮지 않음(비열등) | 잡음 폭 밖으로 높음 |
| 근거 인용률 / rubric | 기준선 이상 / 기준선 −0.1 이상 | 둘 다 높음 |
| 템플릿으로 바뀐 질문 | 0% (후보를 버리고 다음 후보) | — |
| 함정 아닌 질문의 거짓 전제 · 반말 · 깨진 형식이 사용자에게 나감 | 0 | — |
| 지엽적 질문(핵심 주장·위계 상위가 아님) | ≤ 15% | ≤ 5% |
| **핵심성**: 「잘 답하려면 핵심 논리를 이해해야 하나」 (가린 심판 + 사람 표본, §0-1 시험) | ≥ 85% | ≥ 95% |
| 미시 확인 질문(숫자·용어·장 번호 확인) | ≤ 5% | 0 |
| 다른 발표에 그대로 쓸 수 있는 뻔한 질문 | ≤ 10% | ≤ 5% |
| 1·2번 중 핵심 주장(claim root)을 묻는 질문 | ≥ 1개 | 2개 |
| 같은 노드 + 같은 각도 중복 | 0 | — |
| 지시어가 애매한 질문(「이 조건」처럼 가리킬 게 없음) | 0 | — |
| 사람 짝 비교(가림, 40쌍 이상): 앙상블 승 | ≥ 55% | ≥ 65% |

**협업이 진짜인지**
| 기준 | 필수 | 목표 |
|---|---|---|
| 최종 선택된 질문의 작성 모델 분포 | 한 모델이 90% 넘지 않음(넘으면 그 이유를 수치로 설명) | 2개 이상 모델이 각각 ≥ 15% |
| 자기 선호 편향: 심판 모델이 자기 후보를 고른 비율 − 후보 중 자기 비율 | ≤ +10%p (가림 적용 후) | ≤ +5%p |
| 최종 선택 모델은 측정으로 정함 (후보 4개 비교, 사람 짝 비교와 일치도) | 근거 표 있음 | — |

**속도·비용·견고성**

### 3단계 — 발표 음성 기반 3번 이후 질문
