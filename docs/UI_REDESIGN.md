# 척척발표 UI 개선 제안

## 진단: 두 개의 앱이 한 화면에 있다

지금 화면에는 성격이 정반대인 디자인 언어 둘이 섞여 있다.

| | 리포트·리허설 | 삐약 청중석 |
|---|---|---|
| 배경 | `#F2F4F6` 밝은 회색 | `#171b2b` 어두운 남색 |
| 성격 | 토스 계열 — 차분·정확·무채색 | 놀이 — 노랑, 흔들림, 말풍선 |
| 감정 | 없음 (숫자와 판정) | 과함 |

청중석은 귀여운데 **거기 들어가기 전까지는 전혀 귀엽지 않다.** "디자인이 아쉽다"고 느끼는 지점이 여기다. 귀여움이 화면 하나에 격리돼 있어서 나머지는 그냥 대시보드다.

그리고 **'몽총함'은 방향을 잘못 잡았다.** 지금 병아리는 반쯤 감긴 눈·처진 눈썹·느린 흔들림으로 "멍청해 보이게" 설계돼 있다. 그런데 이 병아리들이 하는 말은 *"자료 중요도 1.0인데 한 번도 안 다뤘다"* 같은 정확한 지적이다. **행동과 외형이 어긋난다.** 멍청해 보이는 캐릭터가 날카로운 말을 하면 귀여운 게 아니라 이상하다.

## 방향: 똑똑하고 다정한 병아리

**버릴 것** — 몽총함, 반쯤 감긴 눈, 처진 눈썹, 느릿함
**가져갈 것** — 동글동글함, 노랑, 말풍선, 삐약

> 새 성격 한 줄: **"발표 잘 봤어요! 근데 이거 하나만요."**
> 못 알아들은 게 아니라 **다 알아듣고 살짝 짚어주는** 청중.

제품 메시지와도 맞는다. 척척발표는 "당신 발표에 구멍이 있다"가 아니라 "여기만 채우면 완성"이라고 말하는 제품이다.

## 1. 병아리를 앱 전체로 꺼낸다 (가장 큰 변화)

지금 병아리는 청중석 안에만 산다. 밖으로 꺼내면 앱 전체 성격이 바뀐다.

| 자리 | 지금 | 제안 |
|---|---|---|
| 분석 대기 화면 | 진행률 바 + 자막 | 병아리가 자료를 **넘겨보며** 기다림 |
| 빈 상태 (자료 없음) | 회색 점선 박스 | 병아리가 **빈 무대에 앉아** 있음 |
| 오류 화면 | 빨간 글씨 | 병아리가 **갸웃** |
| 점수 링 | 숫자만 | 점수대별 병아리 **표정** |
| 파비콘·로고 | 파란 사각형 | 병아리 |

**대기 화면이 특히 크다.** 7분을 기다리는데 지금은 막대만 돈다. 병아리가 슬라이드를 한 장씩 넘기며 갸웃거리다 고개를 끄덕이면, 같은 7분이 "일하는 중"으로 읽힌다.

## 2. 캐릭터 시트 다시 그리기

```
지금                        제안
─────────────────          ─────────────────
반쯤 감긴 눈 (--ch-lid)     또렷한 동그란 눈 + 하이라이트 점
처진 눈썹 (M28 34l10 2)     눈썹 제거 — 눈만으로 감정을 낸다
2등신, 몸 27x20             2.5등신, 살짝 갸름하게
sway 3.2s (느림)            sway 2.4s + 말할 때 통통 튐
```

**핵심은 눈이다.** 지금 `.ch-lid` 는 눈꺼풀을 내려 멍한 인상을 만든다. 대신:

- 기본: 검은 원 + **흰 하이라이트 점 2개** — 또렷함이 여기서 나온다
- 말할 때: 눈이 살짝 커짐 (scale 1.1)
- 신남: 눈이 **∪ 모양** (웃는 눈)
- 갸웃: 고개 8° 기울임 + 물음표

눈썹을 빼는 게 중요하다. 눈썹이 있으면 인상이 생기고, 인상이 생기면 "멍청함"이나 "화남"을 읽게 된다. 눈만 있으면 순수해진다.

## 3. 색을 조금 풀어준다

지금 팔레트는 **판정 색 5개가 전부 경고색**이다 (파랑·주황·빨강·보라·회색). 화면 전체가 "뭐가 잘못됐나" 하는 인상을 준다.

```css
/* 기존 판정색은 그대로 두고 '분위기' 층만 얹는다 */
--chick-yellow: #FFD76E;    /* 브랜드 보조색으로 승격 */
--warm-bg:      #FFFBF0;    /* 성공·칭찬 카드 배경 */
--pop:          #FF8FA3;    /* 하트·강조 (지금 .ch-heart 색을 밖으로) */
```

**쓸 자리:**
- `aligned`(잘 설명함) 카드 배경을 `--warm-bg` 로. 지금은 파란 계열이라 "정보"로 읽히지 성취로 안 읽힌다
- 점수 링에 노랑→파랑 그라디언트
- 트로피 문장 카드에 병아리 아이콘 + 노란 테두리

## 4. 마이크로 인터랙션 5개

큰 리디자인 없이 "살아있다"는 느낌을 만드는 것들. 비용 대비 효과가 가장 크다.

1. **점수 링이 차오를 때** 병아리가 같이 커졌다 작아짐 (기존 `countUp` 에 얹기)
2. **탭 전환** 때 내용이 아래에서 8px 올라오며 페이드 (0.24s)
3. **판정 칩 호버** 시 살짝 부풀기 (scale 1.04)
4. **말풍선 등장**이 지금은 즉시 — 아래에서 튀어오르게 (spring)
5. **「객석 들어가기」** 누르면 화면이 위로 걷히며 객석이 드러남 (지금은 페이드)

## 5. 카피 톤 정리

| 지금 | 제안 |
|---|---|
| "아직 설명하지 않았어요" | "여기만 채우면 끝!" |
| "자료와 다르게 말했어요" | "어? 자료엔 이렇게 적혀 있어요" |
| "분석이 아직 안 끝났어요" | "열심히 듣고 있어요… 조금만요!" |
| "판정 확신도" | "얼마나 확실하냐면" |

**판정 자체는 바꾸지 않는다.** `missing` 은 여전히 `missing` 이다. 다만 **말투가 진단서가 아니라 친구의 코멘트**가 되게 한다. 정확성을 낮추는 게 아니라 같은 사실을 다르게 건넨다.

병아리 대사도 마찬가지다. 지금 mock 대사가 `"어... 아 맞다. 그거 얘기 안 했잖아. 흥, 나 계속 기다렸는데."` 인데 이건 삐진 느낌이다. 새 톤:

```
믿:음   "그거 되게 중요해 보였는데… 다음엔 꼭 들려주세요!"
쏠라    "자료 순서랑 살짝 달랐어요. 저만 헷갈렸나요?"
엑사원  "그 설명 진짜 좋았어요! 저 고개 끄덕였잖아요."
엑씨    "어! 그 얘기 자료엔 없던 건데, 재밌었어요."
```

## 우선순위

| 순위 | 항목 | 비용 | 효과 |
|---|---|---|---|
| 1 | 병아리 눈·표정 다시 그리기 | 낮음 (SVG 한 함수) | **큼** |
| 2 | 대기 화면에 병아리 투입 | 중간 | **큼** — 7분을 견디게 한다 |
| 3 | 마이크로 인터랙션 5개 | 낮음 | 중간 |
| 4 | 카피 톤 정리 | 낮음 | 중간 |
| 5 | 색 층 추가 | 중간 | 중간 |
| 6 | 빈 상태·오류 화면 | 중간 | 작음 (자주 안 봄) |

**1번부터 하는 걸 권한다.** SVG 함수 하나(`chickSvg`)와 CSS 몇 줄이라 짧고, 캐릭터가 바뀌면 나머지 판단이 쉬워진다.

## 하지 말아야 할 것

- **판정 색 5종을 귀엽게 바꾸지 마라.** 빨강이 빨강이어야 모순이 모순으로 읽힌다.
- **숫자를 장식하지 마라.** 점수·%·자/분은 지금처럼 또렷한 숫자로 둔다.
- **전체를 다크로 가지 마라.** 청중석만 어두운 게 "무대 밖으로 나간다"는 장치다.
- **애니메이션을 3개 이상 동시에 돌리지 마라.** 이미 `prefers-reduced-motion` 가드가 있으니 새로 넣는 것도 전부 그 뒤에 둔다.
