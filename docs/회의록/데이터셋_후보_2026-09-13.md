# 공개 데이터셋 후보 — "발표 녹음 + 자료 + Q&A" 를 찾아본 결과 (2026-09-13)

> 회의 할 일 #4(종원·선호) 의 출발점. 결론부터: **세 가지(녹음·슬라이드·Q&A)가 함께 있는 공개 데이터는 SOPHIAS 하나뿐이고, 스페인 대학 자료에 사용 동의서가 필요하다.**
> 나머지는 두 가지까지다. 그래서 "우리 발표 녹음 5~10건" 이 여전히 가장 빠른 길이고, 공개 데이터는 **보조 축**(질문 양식 참고 · 그래프 벤치 표본)으로 쓴다.

## 2. 결론과 다음 행동

1. **Q&A 가 있는 한국어 발표 데이터는 없다.** 우리 발표 녹음 + Festa 동의 세션이 유일한 한국어 표본이다 (할 일 #10 그대로).
2. **SOPHIAS 에 DUA 신청** — 종원·선호. 받으면 Q&A 10건만 전사·번역해 "사람이 실제로 한 질문" 20~30개를 뽑고, 우리 질문과 rubric 으로 나란히 비교한다 (멘토링 Q6 과 같은 용도).
3. **LPM 5~10편으로 그래프·정합 벤치 표본** — 개발. 영어라 F-06/07/11 프롬프트가 한국어 전제인 점은 주의. 슬라이드-발화 정렬 정답이 있어 `graph_eval` 의 `align.*` 지표를 사람 라벨과 대조할 수 있다.
4. **EduVidQA·LearningQ 의 실제 학생 질문 50개**를 뽑아 질문 양식(길이·구체 항목·한 가지만 묻기)의 **사람 기준선**으로 삼는다 — 지금 우리 질문의 "어떤 메커니즘" 추상형과 비교.
5. 유료 데이터셋은 위를 다 해 본 뒤에 판단한다. 지금 병목은 돈이 아니라 **Q&A 가 붙은 한국어 발표**다.
