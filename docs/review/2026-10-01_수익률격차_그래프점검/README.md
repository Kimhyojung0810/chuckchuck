## 1-1 — PPT 개념 그래프 (`graph_1-1_tree.png` · `graph_1-1_network.png`)
노드 23 · 루트 1 (제목 「개인 투자자는 왜 시장을 이기지 못하는가」) · 가지 간 연결 14.
1. **발표 주장이 노드에 없다.** 1장 부제 「실력의 문제가 아니라 행동의 문제다」, 2장 결론 「격차는 종목 선택이 아니라 행동에서 만들어진다」 —
   발표의 핵심 주장인데 노드가 없고, 1-2 의 「발표에만 나온 개념」 으로 떨어진다.
2. **「수익률 격차」 가 15장 전부에 붙었다** (weight 1.0). 사실상 모든 장의 배경어라 비중이 부풀었다.
3. **요인과 세부가 한 줄로 섞였다.** 「다섯 가지 행동 요인」 밑에 요인 5개(과잉 매매·타이밍 실패·손실 회피·집중 투자·거래 비용)와
   세부 8개(회전율·최고 상승일·급등일·하락·보유 기간·포트폴리오·분산 투자·비용률)가 형제로 13개. 세부는 각 요인 밑이어야 한다
   (회전율 → 과잉 매매 …). 깊이 상한(3)이 루트 → 요인 묶음 → 요인 → 세부(4단)를 막아 끌어올린 것으로 보인다 [판단].
4. **장 제목이 노드가 됐다.** 「오해와 사실」(12장)·「실행 체크리스트」(13장). 13장의 실제 내용(종목 수 하한 8개 · 연간 총 비용 1% 이하 …)은
   노드가 없어 1-2 의 「발표에만 나온 개념」 으로 떨어진다.
5. 「하락」 처럼 혼자로는 뜻이 없는 이름.

## 1-2 — 발표 대조 (`align_runs.json`, 같은 입력 3회)
판정 3회 동일: aligned 19 · missing 0 · **contradiction 4** · justified_skip 0 · coverage 0.766. 발표에만 나온 개념은 9 · 2 · 0 개로 흔들림.
**contradiction 4개가 전부 오판이다** — 그리고 하필 발표의 핵심 개념들이다 (질문 생성에서 근거 1순위라 「틀리게 말했다」 질문이 먼저 나간다).

| 개념 | 판정 근거 | 실제 |
|---|---|---|
| 수익률 격차 (w 1.00) | 「0.8%라 했는데 자료는 8.7%」 | 받아쓰기 「0.8% 8%」 = 자료 3장 「8.7% vs 7.9% — **0.8%p**」 와 같다. 같은 줄의 다른 숫자(8.7)와 비교했다 |
| 격차는 실재한다 | 「26%p 라 했는데 자료는 4.8%p」 | 받아쓰기가 「2.6%p」 의 소수점을 놓쳤고, 비교도 개인 평균 줄(4.8)로 했다. 자료 「상위 25% 도 2.6%p 하회」 와 같은 말 |
| 성과 상위 그룹 | 「높고 낮은 방향이 반대」 | 「상위 그룹도 못 넘었다면 … 봐야 된다는 신호」 = 자료 「상위 그룹조차 지수에 못 미쳤다 — … 신호」. 같은 뜻 |
| 다섯 가지 행동 요인 | 「수치가 달라요」 | 「**오 번**은 결심이 필요 없습니다」 의 「5번」 은 체크리스트 항목 번호. 차트 수치와 비교했다 |

aligned 는 표본을 보면 맞다 (복리 효과 「1년 차 48만원 … 10년 차 838만원」 등). 발표가 14분으로 거의 모든 장을 읽어 missing 0 은 그럴 만하다.

## 수정 1 — 핵심 주장을 노드로 (2026-10-01)

### 원인
F-06 이 표지를 `개인 투자자는 왜 시장을 이기지 못하는가: 실력 문제가 아닌 행동 문제` 로 뽑는다 — 「이름: 설명」 꼴이라 이름 자리에 **질문(제목)**,
설명 자리에 **주장(부제)**. F-07 은 이름 자리로 노드를 만들어 루트가 질문이 됐고 주장은 요약에만 남았다.
2장 제목(「격차는 종목 선택이 아니라 행동에서 만들어진다」)도 주장인데 「장 제목은 노드로 쓰지 마라」 에 막혔다.

### 바꾼 것 (모든 발표의 루트를 주장 문장으로 통일)
- 프롬프트: 주장 노드 = 짧은 평서문, 질문형 제목·주제어 금지. 주장 노드에 한해 장 제목·결론 문장 사용 허용. **자료의 주장 문장을 그대로 옮기고 바꿔 말하지 않기.**
  출력에 `thesis_claim` 칸 (위계를 parent 칸으로 받은 것과 같은 수 — 이름 규칙만으로는 3회 중 1~2회가 주제어로 남았다).
- 코드: `thesis_claim` 이 평서문이고 자료 낱말이 60% 이상이면 루트 이름으로 (`_apply_thesis_claim`). 「질문: 답」 은 답만 (`_answer_part`),
  80자 넘으면 「주어 + 마지막 마디」 로 줄인다 (`_shorten_claim`). 못 받으면 질문 꼴 루트 이름을 요약의 답으로 바꾼다 (`_claim_label`).
- 예시는 측정 덱과 무관한 주제(도시 열섬). **처음엔 수익률·수면 덱의 주장을 예시로 넣었다가 모델이 그대로 베껴 — 측정이 무의미해서 바꿨다.**
