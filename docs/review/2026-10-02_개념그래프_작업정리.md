# 개념 그래프 · 질문 코치 작업 정리 (2026-10-01 ~ 10-02)

질문 코칭의 1번 과제 「개념 그래프가 제대로 나오는가」 에서 시작해, 그래프 → 측정(벤치마크) → 질문 선택까지 고쳤다.
덱은 `ppt/` 의 11개(수익률격차 · 수면 · 알림 · 부스 A·B·C · 검증용 5)를 썼다. LLM 은 Upstage **Solar(solar-pro3)**.

---

## 1. 개념 그래프

### 1-1. 원인 진단 (f209e54) — `docs/review/2026-10-01_개념그래프_일반원인/`
수익률 한 덱만 고치다가 「다른 PPT 가 와도 제대로 나와야 한다」 로 원인을 일반화했다. 덱 11개 × 3회 진단:
- **F-06 개념 목록이 뒤죽박죽** — 개념 · 주장 문장 · 수치 · 조건이 한 칸에 섞였다. 반찬 IR 은 「성수동」「3개 단지」「12주」(실험 조건)가 루트가 됐다.
- **자료가 가진 구조 신호를 버림** — 표지 부제 · 요약 장 · 장 헤드라인(「01. 과잉 매매 — 거래를 늘릴수록 성과가 낮아졌다」)을 안 썼다.
- **LLM 한 번에 일이 너무 많음** — 노드 고르기 · 위계 · 주장 · 연결을 한 호출이 해서 같은 입력에 노드 8↔26, 루트 1↔4 로 흔들렸다.
- 수익률은 루트가 3/3 질문(「…는 왜 시장을 이기지 못하는가」)이었다.

### 1-2. 재설계 (e017d06) — `docs/review/2026-10-01_개념그래프_재설계/`
- **F-06 종류 있는 추출** — 장마다 주장 · 개념 · 근거(수치·조건)를 나눠 받고, 코드가 꼴로 다시 검사한다
  (명사구 「주장」 → 개념/근거, 「12주」「분석 기간」 → 근거, 그 장 원문에 없는 문장 → 버림).
- **헤드라인을 원문 그대로** 그 장의 첫 주장으로. 「X — 주장」 꼴이면 앞 장 개념 X 를 푸는 장이라 X 밑에 단다.
- **노드는 코드가 정하고**, Solar 는 핵심 주장 고르기 · 장 연결 · 구획만.
- 결과(11덱): 루트 1.33 → **1** · 질문 루트 9% → **0** · 숫자 노드 0.3 → **0** · F-06 항목 누락 15.6 → **0** · 이름 원문 근거율 0.89 → 0.98.

### 1-3. 재현성 · 의미 정확성 · 층 지도 (251ba8f) — `docs/review/2026-10-02_개념그래프_재현성/`
사용자 기준 셋: 같은 PPT 10번 → 같은 그래프? · 원문에 없는 주장·관계를 만들지 않나? · 그림만 보고 구조가 읽히나?
- **재현성** — temperature 0 이어도 Solar 는 개념 단위·상하 관계를 실행마다 다르게 냈다. F-06 · 뼈대 판단을 **3번 병렬로 돌려 다수결**
  (과반 못 든 항목은 버리지 않고 근거로), 장당 주장 4·개념 6 상한, 표지에 적힌 주장이 있으면 그것이 핵심 주장.
- **의미 정확성** — 개념 이름·근거·설명은 그 장 원문에 낱말 60% 이상, 괄호 안 조건(「(성수동 3개 단지, 12주)」)은 근거로.
  개념 위아래는 **자료가 명시한 것만**(같은 장 목록·공식 · 「X — …」 헤드라인 · 장 제목 개념) — 예전엔 「가설 B·C 가 가설 A 밑」 같은 사실 아닌 위계가 생겼다.
  장 간 연결은 원문 한 줄이 두 끝을 함께 부를 때만.
- **층** — 주장은 문장이 부르는 개념 밑, 근거는 같은 장 주장 밑. 주장 밑에 개념이 오지 않는다.
- 결과 (같은 덱 10회, 전 → 후):

| 덱 | 노드 일치 | 위계 일치 | 핵심 주장 같음 |
|---|---|---|---|
| 반찬 IR | 0.63 → 0.93 | 0.48 → 0.75 | 10/10 |
| 수익률 | 0.48 → 0.62 | 0.27 → 0.51 | 6/10 → 10/10 |
| 배달 별점 | 0.53 → 0.57 | 0.41 → 0.47 | 10/10 |

  노드·근거 원문 근거율 1.00, 장 간 연결 원문 근거 1.00. 11덱 모두 핵심 주장 문장이 실행마다 같다.

### 1-4. 같은 개념 묶기 (d3b2503)
이름이 다른 같은 개념이 따로 노드였다. 개념 이름을 **Upstage 임베딩**으로 묶어 유사도 0.7 이상 쌍만 Solar 에게 「같은 대상인가」 를 묻고
과반이면 한 노드로. 수익률 「매매 회전율 = 연간 회전율 = 회전율」, 수면 「끊기지 않는 수면 = 수면 주기 연속성」. 임베딩이 없으면 건너뛴다.

## 3. 질문 코치 (F-08)

### 3-1. 질문 순위 (289432c)
층 그래프에서 깊이는 「개념이냐 주장이냐」 일 뿐인데 깊이 순으로 줄 세워, 차트 범례(「시장지수」「연평균 수익률」)가 핵심 요인과 같은 순위였다.
기둥 주장(「…사전에 정해둔 규칙이었다」)은 후보에도 없었고, 후보를 고쳐도 재정렬(`_rerank`)이 옛 순서로 되돌렸다.
- 깊이 대신 **자료 반복도**(이름이 원문 몇 장에 나오나 · 자식이 덮는 장 · 풀어 쓴 정도)로, 개념·주장을 번갈아, 재정렬이 그 순서를 지킴.

### 3-2. 핵심 개념 커버리지 · 함정 질문 (3cd11e9)
- 요약·결론 장에서 다시 말한 개념 가중(저자가 내세운 기둥) · 이름이 같은 노드는 질문 한 자리만.
- **함정 질문** (일부러 틀린 전제를 깔아 바로잡는지 보는 질문 — 설계상 기능):
  - 차트 축 눈금 「- 80」 + 「회전율(회)」 가 가짜 사실 「80 회전율(회)」 이 되던 것 → 축 눈금 줄 제외, 실제 서술 「회전율 8.4배 차이」 를 뒤집는다.
  - 차트에서 읽은 표의 작은 값(-0.4 → -0.5)은 쓰지 않음 — 순위 뒤집기(「가장 큰 요인은 …」)만.
  - 두 장 이상에서 되풀이한 숫자(「연 4.8%p」)를 먼저.
  - 7개 자리 밖 개념을 데려와 함정을 더 만들지 않음 — 세 번째 함정이 핵심 「규칙」 질문 자리를 빼앗았다. 함정 수 3 → 1.8 (상한 3 은 그대로).
  - 함정은 첫 질문이 되지 않음, 근거 있는 핵심 주장 질문은 자리를 지킴.

결과 (수익률격차, 현재 그래프, 전 6회 / 후 8회):

| 지표 | 전 | 후 |
|---|---|---|
| Top-K Coverage | 0.60 | **0.80** (K4 「규칙」 추가) |
| Redundancy | 0.14 | 0.14 |
| Grounding | 0.32 | **0.42** |
| Adaptivity | 0.93 | 0.93 |
후 8회 모두 같은 질문 7개, 첫 질문은 늘 핵심 주장.

## 4. 실험 — 채택 안 함 (`labs/embed_attention/try_embed.py`)

「Solar 의 사전지식으로 개념을 묶고 위계를 정리하자」 를 시험했다. Solar 는 API 라 내부 attention 은 못 꺼낸다.
- **임베딩 attention** (항목 × 항목 유사도에 softmax): 같은 말·개념↔주장은 잘 붙지만(「예측 능력 → 그 주장」 0.77) 위아래 방향을 모른다.
  「상위 성과 그룹 ↔ 하위 성과 그룹」(0.90) 같은 반대말도 가장 가깝게 나온다.
- **임베딩 후보 쌍 → Solar 방향**: 후보가 낱말 비슷한 쌍뿐이라 진짜 위아래 쌍(「과잉 매매 > 회전율」)이 후보에 없었다.
- **개념 전체 → Solar 위계**: 안정적(일치도 0.91)이지만 다섯 요인이 「복리 효과」 밑에 가는 등 틀린 곳이 많다.
- **자료 위계 고정 + 나머지만 Solar + 검증**: 이유엔 「상위 개념」 이라 쓰고 하위로 붙이는 식으로 이유와 결정이 엇갈리고, 실행마다 골격이 바뀐다.
- **다른 모델**: A.X-K1 (JSON 깨짐 · 반대말을 같다고 함) · EXAONE (긴 질문에 영어 풀이만, JSON 없음) · 믿:음 (401 인증 오류).
→ 위계는 자료 명시 규칙을 유지하고, 임베딩 + Solar 는 **같은 개념 묶기**에만 쓴다 (1-4).

## 5. 남은 것

- **Redundancy 1/7** — 핵심 주장(「실력의 문제가 아니라 행동의 문제다」)과 같은 요지의 K1 주장(「다섯 요인 중 종목 선정 능력에 해당하는 항목은 하나도 없다」)이 둘 다 질문된다. 낱말로는 못 가르고 뜻 비교가 필요하다.
- 그래프 데이터는 여전히 **트리** — 장을 넘는 연결은 근거가 확실한 것만 남겨 거의 없다 (요약판은 같은 개념이 다시 나온 장을 선으로 보여 준다).
- 루트 밑이 넓다 — 자료가 위계를 명시하지 않은 개념은 핵심 주장 바로 밑.
- 배달 별점·수익률 노드 일치는 0.57~0.62 — 흔들리는 건 주로 잎 개념 이름 (제품은 같은 파일이면 저장된 그래프를 재사용).
- 위계를 더 강한 모델로 다시 시험하려면 API 키가 필요하다.
