제품은 **처음 보는 PPT** 에서 돌아야 해요. 그런데 F-07 프롬프트에는 아직 특정 덱에서 온 글이 있어요.

- 규칙 B·D 예시 낱말: focus 덱의 「집중 · 집중 루틴 · 집중력 저하 · 알림 끄기」 (`overfit_scan.py` 가 잡는 유일한 F-07 줄)

앞선 두 A/B 는 이걸 빼면 위계가 흔들린다고 봤어요. 둘 다 **덱마다 표본 2개**였어요.

| A/B | 바꾼 것 | 옛 부모 일치율 |
|---|---|---|
| 09-29 [graph_ab](graph_ab.md) (9덱) | 예시 id 중립화 + 「예시 id 따라 쓰지 마라」 (C) | 0.61 → 0.43 |

| 〃 | 울타리만 | 0.707 → 0.530 |

그런데 옛 잣대는 **루트 이름 하나가 바뀌면 덱 하나를 0 으로** 만들어요. WP-C 울타리 갈래의 제품 대조군 표본 두 개는 루트가 「틈새」·「공강」 으로만 달랐는데 0.917 → **0.000** 이 됐어요.

그래서 이번에는 순서를 이렇게 잡았어요.

1. 잣대부터 고쳐요.
2. 판정 규칙을 **돌리기 전에** 적어요 (이 문서 §3, 이 커밋).

## 1. 잣대 — 정렬 부모 일치 `apa`

코드는 `labs/qa_bench/hier_stab.py`, 약속은 `tests/test_hier_stab.py` 에 있어요.

두 그래프의 노드를 먼저 짝지어요.

1. **같은 이름** — `label_keys` 가 같아요 (조사 「의」·띄어쓰기만 달라요).
2. **비슷한 이름** — 머리말이 통하고(`head_match` ≥ 0.6) 극성이 같아요.
   - 「대출 권수」↔「도서관 대출 권수」 는 짝이에요.
   - 「집중력」↔「집중력 저하」 는 규칙 D 가 부모·자식으로 두는 다른 개념이라 짝이 아니에요.
3. **이름 바뀜** — 남은 노드끼리, 짝지은 자식이 **둘 이상**이고 적은 쪽 자식의 **절반 이상** 겹치면 같은 자리예요.
   - 루트 이름 바뀜은 여기서 짝이 돼요.
   - 짝이 늘면 한 단 위를 다시 봐요 (손자 → 자식 → 루트).

그다음 짝마다 재요.

| 지표 | 뜻 | 쓰임 |
|---|---|---|
| **apa** | 짝 (x, y) 중 부모도 서로 짝이거나 둘 다 루트인 비율 | **위계 안정성 주 지표** |
| cover | 2·짝 수 / (두 그래프 노드 수 합) | 노드 **집합**이 같은가 (위계와 따로) |
| tes | 1 − (지운 노드 + 더한 노드 + 이름 바꿈 + 옮김) / 노드 합 | 전체 편집 거리. 루트 이름 바뀜은 1건 |
| anc | 짝마다 조상 집합 자카드의 평균 | 한 단 옮김에 부분 점수 |
| pa_old | 옛 부모 일치율 | 견주기용 |

`tests/test_hier_stab.py` 가 고정하는 것:

- 루트 이름만 바꾼 6노드 트리: pa_old **0.40**, apa **1.00**, tes 1 − 1/12 (이름 바꿈 1건)
- 서브트리 하나를 옮기면 옮긴 부모 관계 1건만큼 떨어져요 (apa 5/6)
- 머리말이 다른 「혈당 부하」↔「혈당 스파이크」 는 짝이 아니에요

W 가 바꾸는 두 줄:

```diff

+   무너뜨리는 개념 밑에 단다. ("보온성 저하" 는 "보온성" 밑, "외풍 막기" 는 그것이 지키는 "보온성" 밑)
```

- 중립 낱말은 이 조건으로 골랐어요.
  - 벤치 14덱, `labs/qa_verify` 덱, `fixtures/` 어디에도 없어요 (보온·보온성·용품·외풍 막기 0건).

    - 「집중 / 집중 루틴」 → 「보온 / 보온 용품」: 이름이 겹치는 형제.

## 3. 판정 규칙 — 돌리기 전에 적었어요 (2026-09-30 04:50 KST)

`graph_ab2.decide` 가 이 규칙을 그대로 기계적으로 가르고, 사람은 고르지 않아요.

**덱**
- 판정 덱 10개예요: held-out 합성 6(IR·과학·정책·인문·제품·건강) + 합성 2(도서관·자전거) + 실제 2(focus·SK하이닉스).
- 튜닝 덱(수면·수익률격차)은 갈래마다 1번씩, **확인용**이고 판정에 안 들어가요.

**표본**
- base 는 덱마다 6개예요. s0·s1 은 09-29 graph_ab 응답을 되써요 (열쇠가 바이트까지 맞아요). 자전거 덱은 6개 모두 새로 불러요.
- W·I·F 는 덱마다 4개예요.
- 모두 Solar 만 불러요. 예비 A.X 로 조용히 섞이지 않게 막았어요.
- 연결 보강 호출은 모든 갈래에서 빈 응답으로 둬요.
  - 연결은 relates 선만 더해요.
  - 위계·F-26 주장·탐침은 edges 를 읽지 않아요 (`f26_claims`·`_probes` 에 edges 가 없어요).

**잣대**
- 덱마다 표본 쌍 평균을 내요 (base 15쌍, 갈래 6쌍).
- 갈래 값은 그 덱 평균이에요.
- 표준오차는 덱마다 잭나이프(표본 하나씩 빼기)로 재요. 덱은 두 갈래가 같아서 짝 비교에서 빠져요.
- SE_Δ = √(SE_갈래² + SE_base²) 예요. **base 를 같은 조건으로 두 번 돌렸을 때 나올 차이의 크기**예요.

**문 — 다 통과해야 해요**

1. **위계**: Δapa = 갈래 − base ≥ −m, m = min(SE_Δ, 0.05).
   - 흔들림이 커도 0.05 넘는 하락은 통과시키지 않아요 (09-30 되돌림 기준).
   - 이 문은 1 SE 라서, 95% 구간이 겹치는지 보는 것(약 2.8 SE)보다 엄해요.
2. **노드 집합**: Δcover 도 같은 규칙이에요.
3. **무너짐**: 어느 덱도 apa 가 base 보다 0.25 넘게 떨어지면 안 돼요. 09-29 C 갈래 IR 1.00 → 0.19 같은 것을 막아요.
4. **아래 단계** (규칙 경로, 0콜, 덱마다 표본 평균의 덱 합):
   - 심은 탐침 대상 노드·심은 주장·심은 탐침 재현은 각각 ≥ base − max(SE_Δ, 0.5)
   - 헛탐침(정밀도 분모 − 분자)은 ≤ base + max(SE_Δ, 0.5)
   - **대조군(과학·제품) 거짓 긴장은 갈래의 모든 표본에서 0**
   - 0.5 는 「표본 넷 중 둘이 심은 항목 하나를 놓친」 차이예요. 탐침은 제품 경로처럼 자료 원문과 함께 찾아요 (`derive_probes(…, slides)`).
5. **모양**: 세부(깊이 3) 비율의 덱 평균이 ≥ base − min(SE_Δ, 0.05) 여야 해요. 트리를 펴서 apa 를 거저 얻지 않았는지 봐요.

**고르기**
- 문을 다 통과한 갈래 중 **덱에서 온 글이 가장 적은 것**을 넣어요: I > F > W > base.
  - F 와 W 는 덱 글이 같아요. F 는 자료 울타리가 더 있어서 앞에 둬요.
- 통과한 갈래가 없으면 **base 를 그대로 두고** 숫자로 까닭을 적어요.

**순서·예산 (≲ 200콜)**
- 1단계: base 새 표본 42 + W 40 + 튜닝 확인 2 = **약 84콜**이에요. W 를 먼저 가려요.
- 2단계: **W 가 통과했을 때만** I·F 를 돌려요 (약 80콜). I·F 는 W 위에 한 가지씩 더한 갈래라서 W 가 떨어지면 잴 까닭이 없어요.
- 표류 확인: base 의 09-29 표본과 오늘 표본 사이 쌍(옛↔새) apa 가 오늘 표본끼리(새↔새)보다 덱 평균 0.1 넘게 낮으면, base 를 오늘 표본(s2~s5)만으로 다시 가려요.
- 판정 뒤에 표본을 더하지 않아요 (엿보고 더 뽑기 금지).
