## 이어서 — F-08 질문 순위 (층 그래프용)
문제: 질문 후보는 「근거 → 구획 → **깊이** → weight」 순이었다. 층 그래프에서 깊이는 「개념이냐 주장이냐」 일 뿐이라, 핵심 주장 바로 밑의
잎 개념(차트 범례 「시장지수」 「연평균 수익률」)이 핵심 요인과 같은 순위에 서서 weight 로 후보 창을 채웠다. 후보 순서를 고쳐도
`_rerank` 가 옛 키(깊이 → LLM severity)로 다시 줄 세웠고, `_spread_adjacent` 는 핵심 주장 밑 형제 전부를 한 덩어리로 봤다.

고친 것 (`chuckchuck/f08_questions.py`, 층 그래프에만 — 옛 그래프는 그대로):
- **자료 반복도**(`_salience_of`): 노드 이름이 원문 몇 장에 나오는가(개념은 구절 그대로, 주장은 내용어 60% · 파서의 차트 설명 제외)
  ∪ 자기·자식이 앉은 장 + 풀어 쓴 정도(하위 노드 수, 2 까지). 깊이 대신 이것으로 줄 세운다. 두 장 이상에서 되풀이된 말은 요약(도입) 장에 있어도 본론 순위.
- 같은 순위대 안에서 **개념·주장 교차**(`_interleave_kinds`) — 주장은 자료가 바꿔 말해 반복도가 낮게 잡혀 후보 창에서 빠졌다.
- `_rerank` 는 후보 순서를 그대로 따른다 (LLM severity 는 짐작이라 위에 두지 않는다). 핵심 주장 밑 형제는 인접 강등에서 뺀다.
