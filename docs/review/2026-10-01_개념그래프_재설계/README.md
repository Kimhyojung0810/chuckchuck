# 개념 그래프 재설계 — 종류 있는 추출 + 자료 구조 뼈대 (2026-10-01~02)

앞 문서 [개념그래프_일반원인](../2026-10-01_개념그래프_일반원인/README.md)이 찾은 원인 다섯을 한꺼번에 고친다.
덱 11개 · F-06 2회 × F-07 2회 = 덱당 4그래프로 이전(f209e54, 덱당 3그래프)과 같은 잣대로 쟀다 (`bench.py`, 결과 `bench.json`).

## 무엇을 바꿨나
| 원인 | 고친 것 | 코드 |
|---|---|---|
| 1. F-06 목록이 무더기 | 장마다 **주장 · 개념 · 근거**를 나눠 받는다. 모델이 나눈 종류는 코드가 꼴로 다시 검사한다 — 명사구 「주장」은 개념·근거로, 「12주」「분석 기간」「Ward (2017)」 같은 수치·조건·문헌은 근거로, 이 장 원문에 낱말 60%가 없는 주장(다른 장 문장을 끌어온 것)은 뺀다 | `f06_concepts._typed_slide` |
| 2. 자료 구조 신호를 버림 | 장 맨 위의 **헤드라인 문장**(「01. 과잉 매매 — 거래를 늘릴수록 성과가 낮아졌다」)을 원문 그대로 그 장의 첫 주장으로. 「X — 주장」 꼴이면 그 장은 앞 장 개념 X 를 푸는 장이라 X 밑에 단다 | `f06_concepts.headline`, `_typed_graph.assemble` |
| 3. LLM 한 번에 일이 너무 많음 | **노드 집합은 코드가 정한다** (주장·개념 = 노드, 같은 이름은 장을 넘어 한 노드, 근거는 노드에 붙음). LLM 은 ① 핵심 주장(표지·요약·결론 후보 중 고르기) ② 장의 부모 ③ 근거 표현이 있는 장 간 연결 ④ 구획만 | `_typed_graph.call_structure` |
| 4. 겉모양 후처리 | 루트 클램프·연결 개수 보강 호출을 타지 않는다 (루트는 늘 하나, 연결은 할당량 없음). LLM 이 고른 장 부모는 **그 장 원문이 부모 이름을 부를 때만** 받는다 — 안 그러면 핵심 주장 밑 | 같은 곳 |
| 5. 평가가 구조를 안 봄 | 덱 11개 구조 벤치 (`bench.py`) + 회귀 테스트 17개 (`tests/test_typed_graph.py`) | |

옛 저장본(종류 칸이 없는 ConceptDoc)은 옛 길(`f07_graph._call`) 그대로 간다. 계약에 더한 칸(`SlideConcepts.title_kind/claims/evidence/concept_of`,
`ConceptNode.kind/evidence`)은 비면 직렬화하지 않는다.

하류도 맞췄다:
- F-11: 주장 노드는 이름이 문장이라 「이름 토큰이 그대로 이어 나오는가」 로는 언급이 0 이었다 → 발화 문장 하나가 주장 낱말 60% 이상을 부르면 1회.
  노드 40개 넘는 그래프에서 LLM 이 판정을 빠뜨린 노드는 그것만 모아 한 번 더 묻는다.
- 가짜 LLM 에 뼈대 판단(`[TASK] concept-skeleton`) 응답을 더했다.

## 그림 (`png/`, 이전 ↔ 새)
- 반찬 IR: 이전 루트 넷(「월 반복 매출 = …」 · 「성수동」 · 「3개 단지」 · 「12주」), 한 노드 밑 29개 → 루트 「구독자 수보다 중요한 월 반복 매출」, 장별 주장 밑에 그 장 개념, 파일럿 조건·수치는 근거.
- 수익률격차: 루트 「…왜 시장을 이기지 못하는가」(질문) → 표지 부제 원문 「실력의 문제가 아니라 행동의 문제다 — …」. 「다섯 가지 행동 요인」 밑에 요인 다섯, 각 요인 밑에 그 요인을 푸는 상세 장(6~10장).
- 배달 별점: 표지 질문 「별점은 왜 4.7에 몰리는가」의 답(3장 헤드라인)이 루트, 2장 가설 검증이 그 밑, 가설 A/B/C 밑에 지표.
- 알림 · 혈당: 장마다 주장 밑에 그 장 개념.

  녹음에 「움직」이 한 번도 없다 — 이전 그래프가 못 잡던 진짜 빠뜨림. 다만 「과잉 매매 — 거래를 늘릴수록 성과가 낮아졌다」처럼 **바꿔 말한** 주장을
  LLM 이 판정에서 빠뜨리면 폴백이 「누락」 으로 둔다 (보충 판정 뒤에도 노드당 10% 안팎).

## 남은 한계
1. **F-06 실행 차이** — 같은 덱도 F-06 을 다시 돌리면 노드 수가 최대 1.75배 다르다 (혈당 16↔28). 종류 재검사가 모양은 잡지만 무엇을 뽑을지는 모델 몫이다.
2. **주장 문장이 없는 장** — 헤드라인도 완결 문장도 없는 장(혈당 4장 「식후 졸림 · 잦은 허기 · 야간 폭식」, IR 3장 공식)은 그 장 개념이 묶음 없이 루트 밑에 바로 붙는다. 정보는 남지만 루트 밑이 넓어진다.
3. **루트 밑 폭** — 장이 많은 덱은 장마다 주장 하나가 루트 밑에 서서 넓다 (수익률 11~23, 알림 14~17). 요약·결론 장이 핵심 주장으로 흡수되면 그 장의 받침 주장도 루트 밑으로 온다.
4. **노드 수 증가** (20→34, 수익률 25~32→92~116) — 누락 0 의 대가. F-11 이 한 번에 다 못 봐서 보충 판정을 더했고, 그래도 일부는 폴백이다.
5. 핵심 주장은 후보 중 고르기라 표지에 주장이 없는 덱(배터리·미세플라스틱)은 모델 판단에 기대고, 장마다 다른 후보를 고를 수 있다 (수익률·알림 4회 중 2가지 — 둘 다 자료 문장).
6. 가지를 넘는 연결은 줄었다(8.3→2.9). 짐작 연결을 막은 결과지만, Solar 가 장 간 관계를 거의 못 적어서 대부분 규칙(같은 개념 재등장 · 해결 문장 → 문제 개념)에서 온다.
