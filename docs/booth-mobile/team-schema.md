# 팀 카드 — `data/team.json` (v1)

원본은 [`team.schema.json`](team.schema.json). `/hi` 랜딩이 척척발표 소개 다음에 팀원 카드를 한 명씩 보여 준다.
**카드 수는 `members` 배열 길이로 정해진다.** 사람이 늘거나 줄면 이 파일만 고친다 — 코드 수정 없음.

## 칸

팀 공통: `schema:"chuckchuck.team"`, `version:1`, `team_name`(≤20), `project_line`(척척발표 한 줄, ≤50), `contest`(「AI 루키 2026 결선」).

카드(`members[]`, 보여 줄 순서대로):

| 칸 | 모양 | 화면 |
|---|---|---|
| `id` | `^[a-z0-9-]{1,24}$` | 주소 조각(`#/hi/<id>`)·사진 파일 이름. 한 번 정하면 바꾸지 않는다 |
| `name` | ≤10자 | 성(姓)이 확실하지 않으면 이름만 |
| `role` | ≤16자 | 짧은 역할명(알약) |
| `headline` | ≤40자, 해요체 | 한 줄 소개 |
| `did` | 2~3개, 각 ≤40자 | 척척발표에서 만든 것. 확인할 수 있는 사실만 |
| `quote` | ≤60자 또는 `null` | 본인이 준 한마디. `null` 이면 화면에서 숨긴다. 대신 지어 넣지 않는다 |
| `photo` | `assets/team/<id>.(webp\|png\|jpg)` 또는 `null` | `null` 이면 이름 첫 글자 + 병아리 아바타 |
| `links` | 0~3개 `{label≤12, url:https://…}` | 선택 |
| `draft` | bool | `true`=본인 확인 전. 화면엔 안 보이지만, 결선 전 전원 `false` 로 |

사진을 넣을 때: `demo/YEHS_demo/assets/team/<id>.webp`(정사각, 400px 안팎, 60KB 이하 — 화면에선 64px 원) 를 넣고 `photo` 를 채운다. 공개 허용 목록은 이미 열려 있다.
테스트가 파일이 있는지·공개인지 본다.
