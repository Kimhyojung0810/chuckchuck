# Festa 까지 만들 단 하나의 기능 — 「1분 리허설 → 놓친 한 장」 (2026-09-13)

> 사용자 질문: "Festa 까지 딱 하나만 만든다면 무엇인가." 후보 5개를 같은 잣대로 비교했고, 하나를 골랐다.
> 잣대: 부스 3분 안 임팩트 · 3주 안 구현 · A.X 가 흔들려도 도는가 · 측정 가능한가 · 우리 차별점과 연결되는가.

## 0. 결론

**「1분 리허설 → 놓친 한 장」**: 자료 3장을 골라 1분 말하면, 자료엔 있는데 말하지 않은 핵심 **한 장**을 슬라이드와 실제 발화 인용으로 보여 주고, 바로 그것을 묻는 질문 **하나**에 답하게 한다. 3~4분에 끝난다.

왜 이것인가 — 한 문장으로: **우리 차별점 두 개(자료엔 있는데 안 한 말 찾기 · 인용이 실제 발화)를 한 화면에 모으면서, 긴 세션 문제(20~30분)를 설계로 없애고, 있는 부품만으로 만든다.**

## 2. 사용자 이야기 (부스)

1. 관람객이 자기 PDF/PPTX 를 올린다(없으면 준비된 3장). 올리자마자 "팀에 보고하는 발표 같아요" + 핵심 장 3개 추천(개념 weight 상위).
2. "이 3장으로 1분만 말해 보세요" → 슬라이드 보며 60~90초 녹음. 화면엔 장당 20초 진행만.
3. 40초 뒤 **「놓친 한 장」 카드**: 슬라이드 4 이미지 · "여기서 **'4단계'** 를 말하지 않았어요" · 실제로 한 말 한 줄(인용) · "자료는 이렇게 말해요"(자료 인용).
4. 질문 하나: "4단계 중 어디서 시간이 가장 많이 드나요?" — 마이크나 타이핑. 판정은 실제 발화 인용으로. 막히면 힌트 3단.
5. 끝 카드: "다음에 지킬 것 한 줄" + 👍/👎 "이 지적이 맞아요" + (부스) 설문 1탭. 전체 리허설로 이어가기 버튼.

시간: 업로드 30초 · 녹음 60~90초 · 대기 40초 · 질문 60~90초 = **3~4분**.

## 3. 무엇이 있고 무엇을 만드나

| 부품 | 상태 | 할 일 |
|---|---|---|
| 정합 누락 판정 (F-11 `missing`) + 언급 횟수 폴백 | 있음 | 짧은 발화(60초)에서 누락이 과다 판정되지 않게: **고른 3장 안의 개념만** 대상으로 (범위 밖은 `justified_skip`) |
| 질문 심사 우선순위 (모순 > 누락 > …) | 있음 | 1분 트랙(질문 1개)에서 **누락 개념을 반드시 1순위**로 고정 |
| 자료 인용 `evidence_quote` · 발화 인용 백스톱 | 있음 | 카드에 둘을 나란히 |
| 1분 트랙 (`QA_TRACK_LIMITS["1"]=1`) | 있음 | 트랙 게이트 없이 자동 |
| 리빌(f11_reveal) | 있음 | 이 모드에선 리빌 대신 「놓친 한 장」 카드 (리빌은 전체 모드에만) |
| 슬라이드 범위 선택 | **없음** | `nf.slideRange`(장 번호 3개) — 업로드 직후 추천 + 사용자가 바꿈. 리허설 필름스트립·정합·질문이 범위를 따름 |
| 「놓친 한 장」 카드 화면 | **없음** | `#/new` 스텝 4 의 이 모드 전용 렌더 (앱 화면 규율: 주인공 하나, 판정 색 불변) |
| 홈 진입 카드 "1분 리허설로 놓친 한 장 찾기" | **없음** | 부스 기본 진입. 전체 모드는 "제대로 연습하기" |
| 부스 설문 1탭 + 👍/👎 | 일부(피드백 버튼 있음) | 끝 카드에 붙이고 동의 세션 manifest 에 저장 (로드맵 A3) |
| 짧은 브라우저 녹음(webm 60초) STT | **미검증** | 부스 컴퓨터에서 5회 실측 (UX 검토 §1-3) |

예상 공수: 개발 4~6일 (범위 선택 1.5 · 카드 1.5 · 홈·흐름 1 · 설문 0.5 · 실측·수정 1). 10/1 잠금 전 완료 가능.

## 4. A.X 가 흔들릴 때

- 질문 생성이 빈 응답이면 재시도(있음) → 그래도 비면 **누락 개념 템플릿**("자료 4장의 '4단계' 를 발표에서 말하지 않았어요. 4단계 중 어디서 시간이 가장 많이 드나요?")으로 간다. 이 모드에선 템플릿도 의미가 있다 — 빈칸이 화면에 보이기 때문.
- 판정이 JSON 을 못 주면 "판정을 못 받았어요 — 자료는 이렇게 말해요" 로 자료 인용만 보여 주고 끝 카드로. 실패를 실패로.
- STT 실패면 타이핑으로 답하는 길(있음).

## 5. Festa 에서 재는 것

| 지표 | 목표 |
|---|---|
| 관람객당 완주(끝 카드 도달) | 60% |
| 「놓친 한 장」에 👍("맞아요") | 70% |
| 질문에 실제로 답한 비율 | 70% |
| 평균 소요 | 4분 이내 |
| 실패 종류별 건수(STT·빈 응답·판정) | 기록만 |

## 6. 하지 않는 것

- 페르소나 패널·실시간 피드백·리포트 재구성 — 이 기능이 끝난 뒤.
- 새 계약 타입 없음. `contracts.py` 는 건드리지 않는다 (범위는 프론트 상태 + 기존 필드로).
- 전체 리허설 흐름은 그대로 둔다 — 이 모드는 **앞에 붙는 짧은 문**이다.
