## 요약

세 파일(booth.html, booth.js, booth_logic.js)에서 캠 트랙 사용자 인터페이스에 보이는 한글 문구를 감사했습니다. 

1. **해요체 규율 위반**: 경어형 "주세요"/"누르세요"(~시, 과도한 경어 금지) 3건

## booth_logic.js 내보낸 함수의 smoke test 갱신 필요

다음 함수의 반환 문구를 변경하는 경우 tests/js/booth.smoke.mjs 의 대응 테스트를 갱신해야 합니다:

1. **cameraErrorText()** (booth_logic.js:51-57)
   - 테스트: tests/js/booth.smoke.mjs:72-77 (line 72-77)
   - 검증 내용: `L.cameraErrorText()` 반환값이 "Error"를 포함하지 않고, "사진을 찍어 올리" 또는 "다시 누르" 문구를 포함하는지 확인
   - **필요한 갱신**: 새 문구들이 정규표현식 `/사진을 찍어 올리|다시 누르/`에 매칭되는지 확인 필요

2. **countdownText()** (booth_logic.js:188-191)
   - 테스트: tests/js/booth.smoke.mjs:149-151 (line 149-151)
   - 검증 내용: `L.countdownText(3)` 반환값이 "3초"로 시작하고 "고치려면"을 포함하는지 확인
   - **필요한 갱신**: 현재 코드 `"고치려면 자막을 누르세요."`에서 `"누르세요"`를 `"눌러요"`로 변경할 경우, 테스트의 정규표현식이나 문자열 검사 업데이트 필요 없음 (substring match 이므로 "고치려면"은 계속 포함)
