# 자료와 녹음은 이렇게 다뤄요 — 구현 기준 (2026-09-10)

화면(`#/about`, 드롭존 동의 문구)이 약속하는 것과 코드가 실제로 하는 것을 한 표로 맞춘다.

| 약속 (화면 문구) | 구현 | 어디 |
|---|---|---|
| 분석에만 써요. 다른 곳에 넘기지 않아요. | 외부로 나가는 것은 파싱(Upstage)·STT(A.X)·LLM 호출뿐이고, 저장은 이 서버의 `var/data` 다. 제3자 제공 없음. | `demo/bridge.py` |
| 학습에 쓰기로 한 자료만 최대 1년 보관해요. | 드롭존 체크박스(기본 꺼짐) → `?consent_learning=1` → manifest 에 고정. 동의 세션만 원본·분석 산출물·QA 턴·피드백을 남기고 `DEMO_RETENTION_DAYS`(365) 뒤 삭제. | `session_archive.py` `open`·`put_artifact`·`prune` |
| 그 밖의 자료는 분석이 끝나면 하루 안에 지워요. | 동의 없는 세션은 파싱본·받아쓰기 캐시만 남고 `DEMO_CACHE_TTL_HOURS`(24) 뒤 삭제. 원본은 처음부터 안 남긴다. | 같은 곳 |
| 녹음은 받아쓰기가 끝나는 즉시 지워요. | 오디오는 임시 파일로만 존재하고 STT 뒤 `unlink`. 보관소는 오디오 바이트를 받지 않는다. | `bridge.py` `_handle_transcribe` finally |
| 리포트의 「이 발표 기록 지우기」를 누르면 바로 지워요. | `DELETE /api/v1/sessions/{id}` → 디렉터리 통째 삭제 + 메모리 세션 제거 + 브라우저 저장소 정리. 있든 없든 204. | `bridge.py` `do_DELETE`, `app.js` `wireSessionDelete` |

## 최소 원칙 (개인정보보호법 관점의 최소치)

- **목적**: 발표 분석(서비스 제공)과, 동의한 경우에 한해 서비스 개선(측정·기준선·라벨).
- **기간**: 동의 없음 24시간 · 동의 1년. 만료는 시작 때 + 하루 한 번 자동 (`journalctl` 로 확인).
- **삭제 경로**: 리포트 화면의 버튼. 계정이 없으므로 브라우저가 든 `session_id` 가 유일한 열쇠다 —
  브라우저 저장소를 비우면 사용자가 스스로 지울 길이 사라진다. 그때는 운영자가 `var/data/sessions/` 에서
  날짜로 찾아 폴더를 지운다.
- **제3자 제공**: 없음. `Cf-Access-Authenticated-User-Email` 같은 신원 헤더는 저장하지 않는다.
- **목록 노출 금지**: 저장된 세션 목록(`/api/v1/cached-takes`)은 `DEMO_DEV_ROUTES=1` 일 때만, 로컬 개발에서만.
- **형식 검사**: PDF·PPTX 여부를 확장자가 아니라 내용(매직바이트)으로 판별하고, 아니면 디스크에 쓰지 않는다.
- **접근 권한**: `var/data` 는 브리지 사용자 소유 0700. 백업하면 백업도 같이 만료시킨다.

## 학습에 쓰는 것과 안 쓰는 것

- **쓰는 것**: 동의 세션의 파이프라인 입·출력(회귀 측정 코퍼스·또래 기준선), 사용자가 명시적으로 남긴
  피드백(👍/👎·판정 이의·채점 이의·「이건 반복이 아니에요」). 이것만이 라벨이다.
- **안 쓰는 것**: 동의 없는 세션 전부, 오디오, 침묵(피드백 없음 ≠ 동의), 모델 자체 출력을 정답으로 삼는 것.
- LoRA 재학습은 사람이 고친 구간이 30세션·200건 이상 쌓였을 때만 export 해서 저장소 밖에서 한다
  (`docs/DATA_PIPELINE.md` §5).
