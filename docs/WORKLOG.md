  우선순위 규칙: 논리 흐름은 연결 멘트 없음 > 근거 점프, 음성 습관은 핵심 장
  시간 부족·초과 > 속도 > 간투어. 1순위 근거 카드만 펼치고 나머지는 fold 로
  접는다 (rSummary 의 기존 관례 재사용 — 새 문법 발명 없음).
- 남는 숫자 전부에 판정 말을 붙였다: 일치도 % → 「자료 순서를 잘 따랐어요」,
  자/분 → 「권장보다 조금 빨라요」, 쓴 시간 → 「목표보다 N분 길었어요」.
  숫자와 판정 색 5종은 불변 (§14 숫자는 신성하다).
- 정직성: 근거가 없으면 헤드라인을 지어내지 않고 블록째 생략. 실데이터·샘플
  경로 모두 같은 구조, 샘플 배지 유지. 기존 voice-tip 처방 문구는 진단 블록으로
  통합해 중복 제거. 파이프라인·스키마는 손대지 않았다.
- 계획: [.claude/plans/report-tabs-resonance.plan.md](../.claude/plans/report-tabs-resonance.plan.md)
