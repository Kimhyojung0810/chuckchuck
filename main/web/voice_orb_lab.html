ElevenLabs Orb 확인 결과와 제안

원본 확인 (elevenlabs/ui · main, 2026-09-14 커밋 기준)

  • 라이선스 MIT (Copyright 2025 Eleven Labs Inc.). 고치고 옮겨 써도 되고, 저작권 문구만 남기면 돼요
  • 파일 하나 registry/elevenlabs-ui/ui/orb.tsx (498줄). 의존성 three · @react-three/fiber · @react-three/drei(useTexture)
  • 원 하나(CircleGeometry) 위 프래그먼트 셰이더: 극좌표 타원 7개 + 노이즈 고리 2개 + 회색조 → 4색 램프
  • 노이즈 텍스처를 ElevenLabs 공개 CDN(storage.googleapis.com)에서 런타임에 받아요
  • 입력은 agentState(null · listening · thinking · talking)와 음량 0~1(getInputVolume · getOutputVolume)
  • auto 모드는 사인파로 음량을 지어내요(listening 0.55 + sin(t·3.2)·0.35 등). 실제 신호와 상관없이 움직여요

판단 — 셰이더만 옮기고 신호는 우리가 낸다

  • 그대로 쓰면 Q&A 앱(바닐라 JS + 작은 React 번들)에 three · R3F · drei 가 새로 들어와요. 스튜디오는 앱을 iframe 으로 띄우니 같은 three 를 한 번 더 받아요. 지름 120px 구 하나에 비해 너무 무거워요
  • 외부 CDN 텍스처는 오프라인 부스 · 사내망에서 끊겨요 → 같은 성질의 이음매 없는 노이즈를 브라우저에서 만들어 써요
  • auto 모드의 지어낸 음량은 브리프가 금지한 「가짜 파형」이에요 → 쓰지 않고, 실제 음량이 없으면 상태별 고정값 + 느린 호흡만 써요
  • 그래서 셰이더(MIT)를 맨 WebGL 로 옮겼어요. GLSL ES 1.0 이라 WebGL1 · 2 모두에서 돌고, 안 되면 Canvas 2D 로 내려가요. 이미 voice-viz.js 의 GradientOrb 를 같은 방식으로 옮겨 둔 길이에요
  • 바꾼 것: 4색 램프 끝을 검정 · 흰색 → 차콜 · 아이보리로, 생각할 때 타원이 천천히 도는 uSpin, 숨쉬기용 uScale, 가장자리 안티에일리어싱

Q&A 통합 계획 (승인 뒤)

  • 위 띠의 삐약이 자리(qa_stage.js · #bcHost)를 「후광」 으로: 구 지름 약 120px, 삐약이 64px. 웹캠 틀 · 레일은 그대로예요
  • 상태는 qsScene 순간에서 바로: 묻기 → Idle(소리 없는 질문) · 답하기/곧 보내요 → Listening · 생각 → Thinking · TTS 재생 중 → Speaking. 마이크가 실제로 꺼져 있으면 Listening 이 아니라 Idle 이에요
  • 마이크: 녹음 경로(startAnswerRecording) · 발표 리허설은 이미 연 스트림을 그대로 이어요. 실시간 받아쓰기(Web Speech)는 스트림을 내주지 않아서, 같은 출처라 권한을 다시 묻지 않는 재기 전용 스트림을 열어요(지금 meter.js 방식, iOS 는 받아쓰기가 끊길 수 있어 열지 않아요)
  • TTS: 지금 Q&A 에는 소리 출력이 없어요. 생기면 <audio> 를 MediaElementSource → Analyser 에 물려 실제 출력 음량으로 써요. speechSynthesis 는 음량을 읽을 수 없어 상태 모션만 써요
  • React: 지금 voice-viz.js(studio-app/src/voice) 의 GradientOrb 를 이 구로 바꾸고, 신호 어댑터의 「흉내 음량」(사인파)은 지워요

이 페이지에서 보는 법

  • 「마이크 켜기」 를 누르고 말해 보세요. Listening 카드와 큰 구가 내 목소리에 반응해요
  • 「시험 음성 재생」 은 TTS 자리에 쓰는 합성 음성(웹 오디오로 만든 모음 소리)이에요. 실제로 소리가 나고, 그 출력 음량을 재서 Speaking 이 반응해요
  • 「마이크 거부 흉내」 · 「저성능」 · 「움직임 줄이기」 로 대응 상태를 봐요
  • 마이크가 막힌 환경(공유 미리보기 등)에서도 신호 없는 모션은 그대로 확인할 수 있어요
