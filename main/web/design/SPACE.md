# SPACE v3 — 3D 공간 설계 (Horizon OS 방식)

> 10-13 사용자: 「지금 3D 는 멀미가 난다. Meta Quest Horizon OS 처럼」 (BRIEF §5-10).
> v2(시점을 90° 씩 돌림) → **v3: 시점은 고정, 창이 움직인다.** VR 멀미의 가장 큰 원인은 「내 몸은 가만히 있는데 시야 전체가 움직이는 것」 이다. Horizon OS · visionOS 는 그래서 시점을 강제로 돌리지 않는다.

## 1. 원칙 — 멀미를 만들지 않는다

1. **시점(카메라)은 움직이지 않는다.** 회전 · 물러섬 · 고개 · 걸음 흔들림 · 마우스 시선 따라오기 모두 없다.
2. **방 · 지평선 · 바닥선은 그대로다.** 움직이는 것은 창뿐이다 — 창은 「물건」 이라 움직여도 멀미가 나지 않는다.
3. **창의 움직임은 짧고 끝이 부드럽다.** .6~.7초, 감속으로 끝난다. 튕김(오버슈트) 없음.
4. **멈춘 창은 정면 · 기울임 없음 · 1:1.** 글자가 언제나 선명하다.
5. **조작은 손가락을 그대로 따른다.** 끌면 창이 손가락만큼 움직인다(직접 조작). 놓으면 가까운 창으로 맞춰진다.

## 2. 배치 — 내 앞의 곡선 위 창들

```
        ╲ ① ╲    ┌──────── ② ────────┐    ╱ ③ ╱
         (흐림)   │   지금 창 — 정면   │    (흐림)        ④ 는 곡선을 따라 더 오른쪽(보이지 않음)
                  └────────────────────┘
                         ● 사용자 (고정)
```

- 네 단계 창이 사용자를 중심으로 한 **완만한 곡선**(반지름 3.2 m) 위에 차례로 놓인다. 간격 64° — 지금 창이 정면, 이웃 창은 화면 가장자리에 살짝 비친다(다음이 있다는 신호).
- **지금 창**: 정면 · 크기 1 · 불투명. **이웃 창**: 곡선을 따라 비스듬히 · 크기 .9 · 흐리게(.45). 그 너머: 보이지 않음.
- **다음 단계**: 곡선 전체가 한 칸(64°) 미끄러진다 — 지금 창은 왼쪽으로 비켜나고 다음 창이 오른쪽에서 정면으로 들어온다. 감쇠 스프링(반응 .2s) → .6~.7초에 자리 잡는다. 「새 리허설」 은 곡선을 거꾸로 미끄러져 ① 로.
- 공간은 **배경**이다 (10-13 사용자: 정사각형 방 · 네 벽 분할 없이). 사용자를 둘러싼 **원통 배경**(반지름 9 m) · **둥근 바닥**(약하게 비침) · 눈높이 위로 **한 바퀴 이어지는 빛 띠**(지평선 단서) · 바닥과 만나는 그늘 띠. 모서리가 없어 창이 곡선을 따라 미끄러져도 배경이 끊기지 않는다. 움직이지 않는다 — 단계마다 조명 색 · 밝기만 은은하게 바뀐다(§3).

### 2-1. 이동할 때 줌 아웃 · 볼 때 집중 (10-13 사용자)

| | 이동 중 (`motion` → 1) | 멈춤 (`motion` → 0) |
|---|---|---|
| 창 거리 | 곡선 전체가 1.1 m 뒤로 | 3.2 m — 지금 창 정면 1:1 |
| 창 크기 | 6% 작게 · 살짝 위로 | 원래 크기 |
| 공간 밝기 | 방 빛 · 빛 띠가 밝아져 곡선 전체가 보인다 | 주변이 가라앉아(×.72) 지금 창에 집중 |

- `motion` = 남은 거리(또는 끌기 중이면 1)를 빨리 올리고(.08s) 천천히 내린다(.32s) — 다 도착한 뒤에 창이 다가온다.
- 시점(카메라)은 그대로다. 줌은 창이 물러나고 다가오는 것이지 화면 전체가 확대 · 축소되는 것이 아니다(그건 멀미를 부른다).

## 3. 조명 — 단계마다 (움직이지 않고 색만)

| 단계 | 느낌 | 빛 색 | 방 밝기 |
|---|---|---|---|
| ① 자료 올리기 | 아침 작업실 | 중립 미색 `#E8E4DC` | 중간 |
| ② 발표 | 무대 — 주변이 가라앉음 | 금빛 `#C9A96E` | 낮음 |
| ③ 질의응답 | 마주 앉은 대화 | 따뜻한 `#D9B98A` | 중간 낮음 |
| ④ 리포트 | 읽는 방 | 맑은 미색 `#F2EDE4` | 높음 |

스포트라이트는 정면 벽(창 뒤) 하나. 빛 색은 금빛 계열에서만.

## 4. 3D 와 2D 의 경계

| 3D (three.js) | 2D (React DOM) |
|---|---|
| 방 · 조명 · 안개 · 반사 바닥 (가만히) | 자료 · 입력 · 질문 · 판정 · 점수 · 리포트 |
| 창이 곡선을 미끄러지는 움직임 | 버튼 · 폼 · 목록 |
| 유리(굴절) — 창 뒤 방을 굴절 | **카메라 영상 `<video>`** (§6) |
| 음성 구(shadergradient) | — |

## 5. 구현 — React Three Fiber

- 스택 · 빌드: React 19 · R3F 9 · drei 10 · three 0.186 · shadergradient 2.4 → esbuild `js/studio-app.js` (`main/web/studio-app`, `npm run build`).
- **카메라**: (0, 1.6, 0) 에서 정면만 본다. 매 프레임 건드리지 않는다.
- **곡선**: 지금 위치 `f`(소수)를 목표 단계로 감쇠 스프링(`maath/easing.damp`, .2s). 창 k 의 각도 = (k − f) × 64°, 그 각도로 곡선 위에 놓고 정면(사용자)을 보게 돌린다. 크기 · 흐림은 |k − f| 로.
- **창 = drei `<Html transform>`** (고정 층 portal). 멈추면 1:1. 정면에서 60° 넘게 비켜난 창의 DOM 은 감춘다(CSS 3D 가 옆 · 뒤로 넘어간 면을 뒤집어 그린다).
- **유리**: §8. 창과 함께 움직인다(같은 묶음).

## 6. 카메라 정거장 (② 발표 · ③ 질의응답) — 카메라가 중심

- 정면 창 = **큰 카메라 창**(화면 높이의 약 84%, 16:9). 내 모습이 거울처럼(좌우 반전) 창을 가득 채운다.
- 영상은 **창 안의 `<video>`** 로 그린다 (10-13: WebGL 텍스처로 옮기던 것이 검게 나왔다). 언제나 선명하고, 브라우저가 알아서 재생한다.
- 영상 위 작은 창(자료 · 조작 줄 · 질문 · 답)은 CSS 유리(흐림 + 막 + 테두리 빛) — 영상은 WebGL 장면 밖이라 WebGL 유리가 굴절할 수 없다.
- 권한은 「카메라 켜기」 를 눌렀을 때만. 이 페이지 안 새 코드 — 지금 앱 카메라 코드는 그대로.

### 6-1. ④ 리포트 = 지금 앱의 리포트 (10-13 사용자)

- 종이 유리 창 안에 **지금 앱의 리포트 화면**을 같은 출처 iframe 으로(`/index.html#/report`, 없으면 앱이 저장해 둔 `#/report/last`).
- 앱 파일은 고치지 않는다 — 메뉴 · 상단바 감추기, 판(1336×1024)을 창 폭 · 높이에 맞추기만 스튜디오가 넣는다.
- 리포트 밖으로 가는 링크는 스튜디오의 「새 리허설」 이 된다. iframe 은 리포트에 처음 갈 때 싣는다.

## 7. 조작

| 조작 | 동작 |
|---|---|
| 창의 주 버튼 · 상단 단계 표시 | 그 단계로 — 곡선이 미끄러진다 |
| 빈 곳을 좌우로 끌기 | 곡선이 손가락을 따라 움직인다. 놓으면 가까운 창으로 맞춰진다 |
| 흐린 옆 창 누르기 | 그 창으로 |
| 브라우저 뒤로 가기 | 이전 단계로 |

- 시점을 움직이는 조작은 없다. 방향키도 쓰지 않는다(발표 중 ← → 는 슬라이드).
- 움직임 줄이기면 미끄러짐 없이 바로 바뀐다.

## 8. 유리 — liquid-glass

- liquid-glass-js(MIT)의 굴절 셰이더를 three.js 재질로 옮겼다. 배경은 html2canvas 페이지 사진(3D · `<video>` 를 못 찍는다) 대신 매 프레임 그린 방이다.
- 글자 뒤에는 색 막(무대 .55 · 종이 .8)을 깐다.

## 9. 지난 판에서 배운 것

- **v2 (시점 90° 회전, 스프링 · 걸음 · 시선 따라오기)**: 멀미가 난다(사용자 10-13). 시야 전체를 움직이지 않는다.
- **v2 카메라 텍스처**: VideoTexture 가 검게 나왔다 → 영상은 DOM `<video>`.
- **v1 (CSS 3D)**: CSS 원근은 카메라 뒤에 걸친 면을 뒤집어 그린다 → 옆 · 뒤로 비켜난 DOM 은 감춘다.
- drei Html 은 고정 층(portal)에 붙인다 — 첫 인스턴스가 붙을 자리를 못 찾아 사라졌다.
- 헤드리스는 WebGL 흉내 모드(이 VM 은 GPU 가 없어 1~2fps) — 동작은 `studioDebug` 상태로, 모양은 멈춘 사진으로.
