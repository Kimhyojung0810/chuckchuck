# ppt/ — `#/test/qa` 덱 폴더

브리지를 `DEMO_DEV_ROUTES=1` 로 띄우면 `#/test/qa` 가 이 폴더의 덱을 목록으로 보여 주고, 한 번에 질문 코칭까지 태운다.
**git 에는 PDF 와 이 README 만 올린다** (`.gitignore`) — PPTX·녹음·클로바 전사·대본은 로컬에만 둔다.

## 목록에 보이는 이름 — `ppt/decks.json`

`#/test/qa` 는 폴더 이름 대신 `decks.json` 의 **묶음(groups)·제목(title)·버전 설명(version)·순서(order)** 로 보여 준다.
폴더 이름은 부스 화면(`booth_qa.js` 의 `BOOTH_DECKS`)과 검증 도구(`labs/qa_verify`)가 키로 쓰므로 **바꾸지 말고 여기만 고친다.**
설명서에 없는 폴더는 「그 밖」 묶음에 폴더 이름으로, `_` 로 시작하는 폴더는 접힌 「보류」 묶음에 뜬다.

## 폴더 하나 = 덱 하나

```
ppt/<덱 이름>/
  자료 1개        .pptx 또는 .pdf                      ← 필수. 첫 번째 것을 쓴다
  녹음 (선택)     .m4a .mp3 .wav .webm .ogg .aac .flac .mp4   ← 「녹음까지」 가 받아쓰기(STT)로 태운다
  클로바 전사 (선택) 클로바노트에서 내보낸 .txt (00:01 같은 구간 줄)  ← 녹음이 없을 때 녹음 대신 쓴다 (개발용 근사)
  참고/ (선택)    대본 PDF·타임스탬프 사진 등을 넣는 하위 폴더  ← 목록·파이프라인은 안 읽는다. 사람이 보려고 둔다
                  (덱 폴더 바로 아래에 PDF 를 두면 그게 발표자료로 잡힌다 — 꼭 참고/ 안에)
```

- 녹음과 클로바 전사가 둘 다 있으면 **녹음**을 쓴다.
- 같은 자료를 두 번째 열면 파싱은 지난 파싱본(보관소, 24시간)으로 건너뛴다.
- 폴더 이름이 화면 목록 이름이다. macOS 에서 온 한글 이름(NFD)도 그대로 된다.
